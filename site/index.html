Hukuki Veriye Modern ve Güvenli Erişim

Hafif, tip güvenli ve hiçbir ek karmaşıklık içermeyen sıfır-slop mimari.

Yüksek Performanslı Python SDK

HTTP/2 destekli httpx tabanlı asenkron ve senkron arama motoru. SSL doğrulama korumalı, otomatik HTML unescape ve Pydantic veri modelleriyle tam tip güvenliği.

Gelişmiş CLI Arayüzü

Terminalden anında arama yapın. Daire, esas, karar yılı ve kelime filtreleri ile sonuçları JSON veya insan tarafından okunabilir zengin tablo çıktısı olarak alın.

Yapay Zeka için FastMCP

Model Context Protocol (MCP) standardı sayesinde Claude Desktop, Cursor ve otonom yapay zeka ajanlarını doğrudan Türkiye Yargıtay içtihatlarıyla buluşturun.

Claude Desktop Yapılandırması

claude_desktop_config.json dosyanıza aşağıdaki bloğu ekleyerek Claude Desktop üzerinden Yargıtay kararlarını sorgulayabilirsiniz.

claude_desktop_config.json 
{
  "mcpServers": {
    "yargitay": {
      "command": "uvx",
      "args": ["yargitay-karar-scraper", "--mcp"]
    }
  }
}

Mevcut MCP Araçları

FastMCP sunucusu yapay zeka ajanlarına aşağıdaki standart araçları sunar:

yargitay_search
Anahtar kelimeye göre hızlı içtihat taraması yapar.
yargitay_detailed_search
Daire, esas, karar numarası ve yıl bazlı detaylı filtreleme sunar.
yargitay_get_decision
Tekil karar ID değeri ile tam gerekçeli içtihat metnini getirir.
Geliştirici Rehberi

Python SDK ile Programatik Erişim

Asenkron veya senkron olarak doğrudan kodunuzun içerisinden içtihat sorgulayın.

example.py 
import asyncio
from yargitay_karar_scraper import YargitayClient

async def main():
    async with YargitayClient() as client:
        # 1. Anahtar kelimeyle hızlı arama
        results = await client.search(kelime="dolandırıcılık", page_size=5)
        print(f"Toplam bulunan karar: {results.total}")

        for doc in results.documents:
            print(f"- {doc.daire} | Esas: {doc.esas_no} | Karar: {doc.karar_no}")

        # 2. Karar metnini tam detay olarak çekme
        if results.documents:
            first_id = results.documents[0].id
            decision = await client.get_decision(first_id)
            print(f"\nKarar Metni ({decision.id}):\n{decision.metin[:300]}...")

if __name__ == "__main__":
    asyncio.run(main())
